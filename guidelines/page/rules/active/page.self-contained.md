# Self contained

Each page is self-contained, reaches as far as its subject drives the code and stops where the code stops being about that subject. Do not:

- link to or name another knowledge-base page in prose,
- disguise a handoff as 'documented elsewhere', or
- add an ownership column that sends the reader to another page.

A boundary fixes required exhaustive coverage and identifies the intended primary page for a symbol. It guides catalog selection; a symbol assigned to another page may be included here when the local explanation benefits, and follow it as far as the subject requires. Show the arithmetic or mechanism locally; if it is too large, limit the sentence to what this page's shown code establishes.

Remove template residue outside fences: `{{` or uppercase `TODO`, `XXX`, `FIXME`. A source marker explicitly named as such may stay, including a marker preceded by 'the ', 'a ' or 'its ', case-insensitively. A local link ending in `.md`, after dropping its fragment, fails this rule.
