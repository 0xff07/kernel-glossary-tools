# Sufficiency

A reader with only the page open can say exactly which lines run on the documented path. A location link names a site and never substitutes for the code a sentence explains. Name the function and operation; show the relevant source beside the explanation, including re-showing code used in a different subsection.

Read every location link to lines no excerpt reproduces and either justify it as a lookup/census or show its code. A range is reproduced only when every line in it is reproduced; explaining behavior across files needs those source sites shown locally.
