# Banned

Four shapes fail the test however true their content, and this outranks every figure pattern:

- a plain table, a `┌─┬─┐` grid of records by attributes, which belongs in a Markdown table (a grid is a figure only when its cells partition something);
- a plain function-flow graph, nodes that are all function names joined by edges that all mean "calls" (edges that mean feeds, points at, transitions to, is claimed by, gates or is written by are structure and are welcome; a swimlane that would survive deleting all but one lane is this shape wearing lanes);
- a plain listing of struct members, a box nothing exits;
- and plain text in a fence.
