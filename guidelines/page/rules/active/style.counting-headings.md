# Counting headings

A heading names what the section is about; the count opens the paragraph beneath it.

| Pattern | Kind | Scope | Unless | Exception |
|---|---|---|---|---|
| `^(\d\|(<number word>)\b)` | violation | heading rows of level 3 and 4 outside the catalog sections | | none |

`<number word>`: one through twenty, thirty, forty, fifty, sixty, seventy, eighty, ninety, hundred.
