# Spine

DETAILS is organized as the model or the journey: one subsection per phase in run order, or per role, state or class, with each cataloged symbol shown inside the phase where it acts. Plan the relationships the reader needs to understand, then place the required symbols and source within that sequence.

Place variants and supporting helpers where they explain a condition of the main mechanism, returning to its object and current state afterwards. One subsection per symbol in catalog order is the failure to avoid.
