# Reshown

A paragraph that reasons about lines the page shows in another subsection shows them again beside itself, a short run within the local re-show target, with its own provenance, instead of sending the reader back: read twice in two contexts, a line is learned rather than looked up. A re-show is short; the walk through the function is where the function is read whole.

A definition read in pieces is not re-shown: a later paragraph links the members it reasons about. To check, read every location link in prose whose lines the page reproduces only in another subsection, a table row being a lookup, and every unit that shows again more lines than the target.

Target about 3–12 reproduced source lines for a re-show. This is a reading target, not a hard rejection threshold. Keep its own provenance and enough enclosing context to identify the construct.
