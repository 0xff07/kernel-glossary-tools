# Specifications

SPECIFICATIONS cites the normative source of the model, each entry carrying what a source comment or commit message gives and nothing more: `<spec name>, section <N.N>: <section title>` where the tree gives all three, and otherwise the name with the section number, the title, the revision or the document number it does give, the citing site named; a specification the tree never cites is not listed; when no specification applies, the section says so.

A model no specification defines is a disclosed synthesis that names its on-disk sources and keeps every fact under it cited.
