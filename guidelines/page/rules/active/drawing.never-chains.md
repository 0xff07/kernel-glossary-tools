# Never chains

A call chain is never drawn as a call tree: the nested, indented function graph that trace-cmd prints, A calls B which calls C, one box or one line per call with an arrow to the next, asserts nothing a sentence lacks, and a single arrow chain in a box is that tree in another dress.

The relationship a chain carries is drawn as what it is, under the trigger table: the actors handing work to each other as a swimlane, the intervals as a Gantt, the structure the calls act on as its figure, each lane or bar an actor, a place or an object and never a function nested in the one that called it. A chain that one sentence states, with no hand-off, no interval and no structure to show, stays prose.
