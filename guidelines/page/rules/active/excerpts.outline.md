# Outline

A function or a definition walked in two or more pieces is outlined before its first piece: a table with the columns piece, lines and stage (for a definition, the member group), one row per piece in order, `❶ tb.c:319-332 asks for enhanced uni-directional`, and each piece's introducing sentence carries its complete mark, so the reader holds the shape of the construct before reading it and always knows which piece this is.

Number independent prose series with recognized prose families, for example ❶ then Ⓐ, never with the ①–⑩ and ➊–➓ reserved for figures; each series counts from its family's first symbol without a gap. Outline rotation is independent of figure rotation.

Outline marks count independently of figures. Recognized prose families include ❶–❿, ⓫–⓴, Ⓐ–Ⓩ, ⓐ–ⓩ, ⓵–⓾, 🅰–🆉, ⑴–⒇ and ⒜–⒵; these are examples rather than a whitelist. Start each series at its first symbol without a gap. Never use the reserved ①–⑩, ➊–➓ or the unused ⑪–⑳ for a prose series; adjacent outline series use different recognized families.

The outline table is recognized by its first header cell, which contains the word `piece` in any case; each row's first cell is the piece's mark (backticks allowed) and its second cell the location `file:A-B` of the piece, links reduced to their text. The table:

- stands before the fence of the first piece, after any earlier outline, and names the construct's file by base name in its rows, even when another cited file shares that base name, since an outline cell is no location link and takes no path, whichever other files the page cites;
- its rows, in order, equal the pieces as the page shows them, each from the first to the last line of the construct the piece reproduces, so a row's range is the piece's reproduced construct lines, not the fence's extent, and a first piece that opens at the comment above a definition names the definition's opening line; and
- the prose line directly above each piece's fence carries that piece's mark as a complete mark.
