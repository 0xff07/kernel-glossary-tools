# Model

Every page carries its model figure under the lead or in SUMMARY: the objects and relationships the page is about, or its complete primary journey, so the reader holds the map before DETAILS.

The model figure's legend is read like any other legend: every mark it draws has an entry, every entry's site is reproduced on the page and lies in the function the entry names, and its marks count in the page's family rotation.
