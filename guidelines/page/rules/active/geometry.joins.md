# Joins

At an intended join, adjacent glyphs open toward each other: horizontal neighbors have right and left connections, vertical neighbors down and up at the same display column. Choose each corner and junction from all the directions it joins; a trunk continuing through a horizontal line needs `┼`, while `┴` has no downward connection.

Apply the same directions to heavy, double and dashed lines, using a mixed junction such as `╤` or `╧` where line styles meet. An arrow's shaft reaches the back of its head. Distinguish a crossing without a connection by a gap, bridge or explicit guide convention; keep intentional gaps, labelled endpoints and open axes identifiable.

| glyph | connects |
|---|---|
| `─` | left, right |
| `│` | up, down |
| `┌` / `┐` | right, down / left, down |
| `└` / `┘` | right, up / left, up |
| `├` / `┤` | up, down, right / up, down, left |
| `┬` / `┴` | left, right, down / left, right, up |
| `┼` | up, down, left, right |
