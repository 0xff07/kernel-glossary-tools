# Figure tabs

Use spaces, never tabs, inside figure fences, including titles, legends and annotations. A figure is a non-C fence containing at least one box-drawing or block character (U+2500–U+259F), arrow (U+2190–U+21FF) or geometric-shape character (U+25A0–U+25FF). A fence whose info string is exactly `c` is a source excerpt even when its code contains those characters. Source excerpts retain their original tabs; quotation fences and prose are outside this rule.
